# AHP-decision-tool / 层次分析法(AHP)在线决策工具
> 用科学方法解决选择困难症！一个简单易用的层次分析法决策工具，帮你量化复杂决策。A simple and user-friendly Analytic Hierarchy Process (AHP) decision-making tool to help you quantify complex decisions.

## 🎯 这是什么？

层次分析法(Analytic Hierarchy Process, AHP)是一种系统化的决策分析方法，由美国运筹学家托马斯·萨蒂(Thomas L. Saaty)在20世纪70年代提出。它能够把复杂的决策问题分解为多个层次和因素，通过两两比较确定各因素的权重，最终给出最优方案。

## ✨ 特性

- 🚀 **开箱即用** - 单个HTML文件，双击即可在浏览器运行
- 📱 **响应式设计** - 支持桌面端和移动端
- 🎨 **直观交互** - 可视化的评分系统和结果展示
- 💾 **无需联网** - 完全离线可用，数据本地计算
- 🔒 **隐私安全** - 所有数据仅在本地浏览器运行，不上传服务器
- 🎓 **教学友好** - 适合此前没接触过AHP方法的同学使用

## 🎬 快速开始

## 🧮 算法说明

本工具使用标准的AHP算法：

1. **构造判断矩阵** - 基于两两比较结果
2. **归一化处理** - 对每列进行归一化
3. **计算权重向量** - 取行平均值
4. **一致性检验** - 确保评分的逻辑一致性
5. **综合评分** - 加权求和得到最终结果

评分采用萨蒂的1-9标度法：

| 标度 | 含义 |
|------|------|
| 1 | 两者同样重要 |
| 3 | 前者比后者稍微重要 |
| 5 | 前者比后者明显重要 |
| 7 | 前者比后者强烈重要 |
| 9 | 前者比后者极端重要 |
| 2,4,6,8 | 介于上述判断之间 |
| 倒数 | 后者比前者重要的程度 |

## 💡 使用技巧

1. **准则数量适中** - 建议5-7个，太多会增加比较难度
2. **保持一致性** - 如果A比B重要3倍，B比C重要2倍，那A比C应该重要约6倍
3. **多次调整** - 可以随时修改评分，重新计算结果
4. **结合实际** - AHP是辅助工具，最终决策还要结合实际情况
